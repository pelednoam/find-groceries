      How Basket knows

      Nothing here comes from a cash register. Basket reads what shoppers wrote and turns it into signals — useful for ranking, useless for exact money. There are no prices anywhere on this site: the price column is a reputation score, not a total.

      1. Collect

        9.6 million posts and comments from r/boston, r/CambridgeMA and r/Somerville, plus 135,345 Google reviews of the same shops.

      2. Filter

        Keep only the 0.3% that name a store and say something evaluative about it.

      3. Extract

        Read each one with a language model into structured claims — which store, which department, positive or negative, cheap or dear.

      4. Weigh

        Score every claim by how directly the text supports it, how old it is, and how it was voted, then roll them up per store, per branch and per item.

      What it is not

      • Not prices. There is no price data here at all. “Cheap” means people say it is cheap, which tracks reputation more than this week's shelf.
      • Not a survey. Reddit is not a representative sample of shoppers, and people post more readily about annoyance than satisfaction.
      • Not current. Claims span many years. Older ones are down-weighted, faster for things that change quickly than for structural price gaps.
      • Not independent. One thread can contain many voices agreeing with each other. Caps limit how much one document or one author contributes, but a local consensus is still one consensus.

      How a number is built

      Each claim gets a weight from three things: how directly the text supports it, how old it is, and how the comment was voted. Weights are summed per store, branch and category, then shrunk toward neutral so a cell with one claim reads closer to 0 than a cell with forty saying the same thing. A score near zero can mean “genuinely mixed” or “barely any evidence” — the claim count beside it tells you which.

      Combining the two sources

      Google's ratings rank the stores nearly as this corpus does (r = +0.86) but occupy a third of the range, bunched near the top the way star ratings always are. So the correction is a rescale — — fitted across every store that has both, with leave-one-out error against 0.434 for guessing the average. A literal per-store offset would have been twenty parameters for twenty stores: a perfect fit that erases every disagreement and hands back whichever source it was anchored on.

      The two are then combined by inverse variance, which decides the mix on its own. Whatever remains unexplained after calibration () floors how precise a Google estimate can be, so this corpus keeps almost all the weight where it has thousands of claims and cedes it where it has one.

      Only counts and averages are published from the Google dataset. No review text, author name or user id appears anywhere in this site or its data file.
